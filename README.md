☁️ Облачная микросервисная платформа Digital-WM

Я создаю собственную облачную инфраструктуру на основе микросервисов — для медицинских ботов, AI-модулей, обработчиков вебхуков, асинхронных задач и Диптихов.
Стек полностью совместим с Kubernetes, Docker, Prometheus и CI/CD.

🔧 Технологии

Kotlin · Rust · Ruby · Node.js · Docker · Kubernetes · Prometheus · Grafana · OpenAPI
